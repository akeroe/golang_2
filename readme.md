# Money Transfer System

Учебная система денежных переводов между пользователями, написанная на Go.


## Возможности

- Создание пользователей и управление балансами.
- Пополнение и снятие денежных средств.
- Переводы между пользователями по ID.
- Хранение пользователей в `map`, а транзакций — в очереди.
- Конкурентная обработка транзакций через горутины и каналы.
- Синхронизация воркеров с помощью `sync.WaitGroup`.
- Защита операций с балансом через `sync.Mutex`.
- Проверка некорректных сумм и обработка ошибок.

## Версии проекта

| Ветка | Описание |
|---|---|
| `v1` | Структура User, методы Deposit и Withdraw |
| `v2` | PaymentSystem, Transaction и обработка переводов |
| `v3` | Конкурентная обработка через каналы и воркеры |
| `v4` | Защита баланса через Mutex и дополнительные проверки |

## Запуск

Необходимо установить Go.

Клонировать репозиторий, переключиться на ветку `v4` и выполнить:

`go run main.go`

Для проверки гонок данных:

`go run -race main.go`

На Windows для Race Detector требуется включённый CGO и совместимый C-компилятор.

## Особенности реализации

Транзакции передаются воркерам через общий канал. Количество воркеров фиксировано и не зависит от количества переводов.

Каждый пользователь имеет собственный Mutex, защищающий операции с балансом.
